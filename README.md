# brand-ai-chatbot

A tool that helps solo founders create brand guidelines and logos :)

## Installation

This codebase is built on basic HTML, CSS and JS so it requires no form of installation for now

## Usage

Just open the index.html file on your browser

## How I made this project

I decided to start working on this because I was inspired by Peter Design Company, I decided that I was going to automate the process of creating stunning simple logos that stands the test of time!

I am working on this project using HTML, CSS and Javascript when I see the idea works then I'd make it available to everyone ;)
